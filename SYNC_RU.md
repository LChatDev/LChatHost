Актуальные исходники синхронизированы с установкой на REG.RU. Нужны PHP 8.2+, PDO MySQL, mbstring, fileinfo, GD и OpenSSL. Для шлюза и вебхуков нужен cURL.

## Обновление работающей установки

1. Сохраните резервную копию БД, config.php и файлов пользователей. Отдельно сохраните ключ шифрования сообщений: он нужен для чтения прежних сообщений.
2. Обновите исходники и ресурсы вместе. Сохраните собственный config.php и рабочие данные.
3. Проверьте новые параметры config.example.php. В public_url укажите свой HTTPS-адрес.
4. В storage_dir укажите доступное для записи хранилище загрузок. По умолчанию это files рядом с app.php. Если прежние файлы лежат в другом месте, укажите существующий путь.
5. Настройте SMTP-хост, порт TLS (465), логин и пароль в приватном config.php или переменных LCHAT_SMTP_HOST, LCHAT_SMTP_USER, LCHAT_SMTP_PASSWORD. Для подтверждения почты и восстановления пароля нужна рабочая отправка SMTP.
6. Проверьте подтверждение почты, вход, восстановление пароля, отправку и удаление сообщения, загрузку файла и звонок между двумя сетями.

Рабочие доступы, аккаунты и вложения пользователей хранятся вне публикуемых исходников.

## Новая установка на PHP-хостинге или Windows

Скопируйте config.example.php в config.php, задайте MySQL и случайный install_key, затем выполните инструкцию установки из README репозитория. Включите расширения именно у того PHP, которым запускается веб-сервер. Настройте HTTPS и правила Apache Rewrite. Встроенный сервер PHP подходит для локальной проверки.

Зарегистрируйте настроенного первого администратора и завершите установку. До публикации своего сервиса заполните реквизиты оператора, контакты и возвраты в шаблонах документов. Для оплаты нужна собственная настройка платёжного провайдера.

## Раздельное размещение

Сначала обновите LChatHost, затем LChatWeb. Задайте одинаковый длинный случайный proxy_secret на обеих сторонах. В LChatWeb укажите backend.mode=pc и backend.url с HTTPS-адресом LChatHost. Сертификату должен доверять PHP cURL. На LChatHost выполняются сессии, сообщения, операции с приватными файлами, почта и сигнализация звонков. LChatWeb отдаёт публичные ресурсы и передаёт поддерживаемые PHP-запросы серверу.

Публичные эмодзи и подарки находятся в assets/lchat-emoji и assets/lchat-gifts веб-репозиториев. При раздельном размещении они нужны на LChatWeb. Пользовательские файлы хранятся на LChatHost.

## Интерфейс и боты

Включены пиксельная тема с оригинальным логотипом, светлый/тёмный режим, дополнительные темы, мобильная навигация и пиксельные аватарки. Возможности Bot API — опрос, вебхуки, файлы и клавиатуры — описаны в docs.php. Код пользовательских ботов и обработчик вебхуков запускаются отдельным процессом или cron. Создание сайтов и компилятор требуют соответствующего бота и рабочего процесса.

TURN размещается отдельно. Укажите собственные адреса и секрет TURN, опубликуйте порт слушателя и диапазон UDP relay, синхронизируйте часы для временных ключей. Инструкции Windows/Linux и туннелей находятся в гайдах звонков. Звонки на реальных устройствах проверяются отдельно.

LChat полностью создан с помощью ИИ и использует сторонние компоненты с собственными лицензиями.
