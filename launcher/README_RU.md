# LChatHost Panel

Скачайте файл для Windows или Linux (x86-64) с суффиксом `-ru`. На Windows запустите EXE. При необходимости нажмите «Установить Docker Desktop» и завершите настройку Docker и WSL 2.

На Ubuntu 24.04 выполните в терминале:

~~~sh
chmod +x LChatHost-linux-amd64-ru
./LChatHost-linux-amd64-ru --install-docker
./LChatHost-linux-amd64-ru
~~~

Если Docker сообщает об отказе доступа, настройте доступ к сокету по [инструкции Docker](https://docs.docker.com/engine/install/linux-postinstall/). Панель выводит локальный адрес в терминал и открывает его в браузере. Держите панель открытой, пока управляете сервером.

1. Введите HTTPS-адрес **LChatWeb** и нажмите «Установить и запустить сервер». Панель соберёт Apache/PHP, запустит MariaDB и сохранит настройки. Для первого запуска нужен интернет. Если порт 18365 занят, освободите его.
2. Выберите временный туннель для проверки. Для постоянного адреса создайте туннель Cloudflare, укажите в настройках сервиса `http://backend:80`, сохраните токен через форму запуска и нажмите «Постоянный туннель».
3. В конфиге LChatWeb укажите адрес туннеля и `proxy_secret` из панели. Завершите установку через `install.php` на LChatWeb с ключом из панели. См. [инструкцию хоста](../doc_RU.md).
4. Для звонков укажите параметры собственного TURN при необходимости. Туннель проводит HTTPS-трафик приложения. TURN для медиа настраивается отдельно.

«Остановить всё» сохраняет тома базы и файлов. Для сборки четырёх файлов из клона репозитория нужны Go и Python. Запустите `python launcher/build.py`.
